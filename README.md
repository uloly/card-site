# MyCard

منشئ بطاقات تهنئة تفاعلية باللغة العربية باستخدام Node.js وExpress.

## التشغيل محليًا

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm start
```

افتح `http://localhost:3000` في المتصفح. يمكن تغيير المنفذ عبر متغير البيئة `PORT`.

## رفع المشروع إلى GitHub

ارفع ملفات المشروع إلى مستودع GitHub. يستثني `.gitignore` مجلد `node_modules` والبطاقات والصور والصوت المرفوعة محليًا؛ هذه الملفات قد تحتوي بيانات خاصة، ويُعاد إنشاء مجلدات البيانات عند تشغيل الخادم.

هذا المشروع يحتاج إلى خادم Node.js؛ GitHub Pages وحده لا يشغّل واجهة Express الخلفية أو يحفظ الملفات المرفوعة.
